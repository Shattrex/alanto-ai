ALANTO brand asset slots
========================
Replace these placeholder files with the final logo files (same names):

  alanto-symbol.svg      symbol only
  alanto-wordmark.svg    wordmark only
  alanto-horizontal.svg  symbol + wordmark
  alanto-white.svg       single-colour white lockup (dark backgrounds)
  alanto-black.svg       single-colour black lockup (light backgrounds)
  alanto-favicon.svg     browser tab icon

Then set  useFileAssets: true  in  src/config/brand.ts
(the site's one global logo switch).
